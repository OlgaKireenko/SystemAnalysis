# 1. Сценарий и ресурсы API

## Пользовательский сценарий

Бизнес-пользователь банка работает с продуктовыми предложениями и использует продуктовый сервис для управления кредитными продуктами.

В рамках сценария пользователь может создавать кредитные продукты, просматривать существующие продукты, изменять их параметры, а также активировать и деактивировать продукты.

Каждое изменение кредитного продукта должно фиксироваться в истории изменений с указанием пользователя, даты и времени изменения.

## Ресурсы API

| Ресурс             | Назначение                                                                                                              | Source of Truth    |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `CreditProduct`    | Хранение и управление актуальной информацией о кредитном продукте и его текущем статусе                                 | Продуктовый сервис |
| `ProductChangeLog` | Хранение истории изменений кредитных продуктов с информацией о выполненных изменениях, пользователе и времени изменения | Продуктовый сервис |
