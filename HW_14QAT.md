| 1 | **Производительность** | При создании кредитной заявки система должна обработать запрос и вернуть клиенту результат скоринга не позднее чем за **15 секунд** при нагрузке до **100 запросов в секунду**.                                                               | Нагрузочное тестирование, измерение времени ответа API                                                |
| 2 | **Доступность**        | При штатной эксплуатации сервис оформления кредитной заявки должен быть доступен не менее **99,9% времени в месяц**, за исключением заранее запланированных технических работ.                                                       | Мониторинг доступности, анализ логов и метрик за месяц                                                |
| 3 | **Безопасность**       | При входе в мобильное приложение система должна проверять наличие действующего токена и соответствующей роли у пользователя - MICROLOAN_HOLDER и только тогда отображать баннер - "Онлайн микрозайм" | Тестирование авторизации и ролей                                  |
| 4 | **Повторное использование**         | Модули кредитного конвейера, взаимодействующие с внешними системами (например, Бюро кредитных историй) должны быть универсальными, иметь возможность переиспользоваться в других кредитных продуктах                               | Анализ архитектуры и проверка повторного использования модуля в другом кредитном продукте без доработки его основной логики |
| 5 | **Сопровождаемость**   | При возникновении ошибки обработки кредитной заявки система должна записывать в журнал **идентификатор заявки, время, код ошибки и техническое описание**, чтобы ошибку можно было найти по `claimId`.                               | Проверка логов после искусственного возникновения ошибки, поиск записи по `claimId`                   |
